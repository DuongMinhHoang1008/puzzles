## Fixes found through deeper QA

- UI-only `interpret_move` returns an empty static sentinel. Freeing it corrupted state for Mines/Pegs; only owned nonempty strings are now freed. Both games pass real input/history/restore afterward.
- Statusbar text now updates from engine callbacks, including timer ticks and UI-only changes, rather than waiting for another committed move.
- IndexedDB read failure is distinguished from corrupt data. Storage failure allows play; corrupt save requires explicit recovery. Failed writes remain dirty for retry and disposal is idempotent.
- Touch presses are deferred until a tap/drag is identified, allowing a second finger to cancel a pending game gesture before pinch zoom. Pan mode blocks game input; geometry stays in engine logical units.
- Save metadata is owned by the session, including once-only celebration and conservative app assistance. It is not inferred from every game’s current history flag.
- Added three substantive EN/VI rule paragraphs to each game and corrected inaccurate Black Box, Pearl and Same Game instructions against the local manual. Rectangles help uses the actual manual chapter `rectangles` while engine/module ID stays `rect`.
- Board thumbnails are actual engine captures; all 38 files and fixture references are checked by production asset validation.
